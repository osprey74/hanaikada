# 花筏 操作マニュアル

Bluesky のフォロー中アカウントのメディアを眺めるデスクトップアプリ「花筏」の操作ガイドです。

- 対応 OS: Windows / macOS
- 閲覧専用（投稿・いいね・リポスト・フォローは行いません）

---

## 1. ログイン

1. アプリを起動すると、ログイン画面が表示されます。
2. Bluesky の **ハンドル**（例: `yourname.bsky.social`）を入力します。
3. **App Password** を入力します。
   - アカウント本体のパスワードは使えません。
   - Bluesky の **Settings → Privacy and Security → App Passwords** で発行してください（画面の「発行手順を開く」からも辿れます）。
4. 「ログイン」を押します。

ログインに成功すると、以降は再起動してもセッションが自動で復元されます（App Password は保存されず、更新用トークンのみが OS のキーチェーンに安全に保管されます）。

---

## 2. メディアの取り込み（同期）

### 初回同期

初回は空のグリッドに「初回同期をはじめる」ボタンが表示されます。押すと、フォロー中アカウントのメディア投稿をさかのぼって取り込みます。進捗はステータスバーに表示され、途中で中断できます。

> Bluesky のタイムライン（フォロー中フィード）が返す履歴には上限があり、取り込めるのは概ね直近の数千件です。それより過去は取得できません。

### 差分同期

以降は、ヘッダーの「**同期**」ボタン（またはキー `r`）で新着だけを取り込みます。既に取り込んだ投稿に達した時点で自動的に打ち切るため、短時間で完了します。

レート制限を受けた場合は自動的に待機し、ステータスバーに待ち時間が表示されます。

---

## 3. グリッドを見る

- 画像・動画の投稿だけが、新しい順に高密度で並びます。
- **複数枚の投稿**は 1 タイルにまとまり、右上に枚数バッジが付きます。
- **動画**には再生アイコンが付きます。
- **リポスト**経由の投稿には控えめなリポスト印が付きます。
- タイルにカーソルを合わせると、投稿者ハンドルと相対時刻が表示されます。
- **タイルをクリック**すると拡大表示（ライトボックス）が開きます。

下端までスクロールすると自動で続きを読み込みます。同期中に上部へ新着が届いた場合、スクロール位置は保たれ、「新着 N 件」のピルが表示されます（クリックで反映）。

---

## 4. 絞り込み（左サイドバー）

すべての条件は AND で組み合わされます。

- **種別**: すべて / 画像 / 動画
- **期間**: 今日 / 7日 / 30日 / すべて / カスタム
- **リポストを含める**: オン／オフ
- **投稿者**: 一覧から複数選択（ハンドルで絞り込み可）
- **検索**（上部の検索欄）: ALT テキストと本文を全文検索します。3 文字以上で部分一致（日本語対応）。

条件はアプリを再起動しても復元されます。`Esc` キーで、検索解除 → 絞り込み解除 の順に解除できます。

---

## 5. 拡大表示（ライトボックス）

タイルをクリックすると全画面で表示されます。

- 同一投稿に複数のメディアがある場合、`←` / `→` で送れます。
- 動画は `Space` で再生／一時停止できます。
- `o` で元投稿を既定ブラウザで開きます。
- `Esc` で閉じます（グリッドのスクロール位置は保たれます）。

---

## 6. モデレーション（ラベル・ミュート・ブロック）

- Bluesky のラベラー設定を反映し、警告系ラベル（成人向け・性的表現・露出・衝撃的な映像など）が付いたメディアは**既定でブラー**されます。タイルをクリックすると、そのタイルだけ一時的に表示できます（解除はセッション内のみ保持）。
- ミュート／ブロックはサーバー側でタイムラインに反映済みですが、過去に取り込んだ分はローカルに残ります。設定の「**ミュート/ブロックを反映**」で最新の一覧と突き合わせ、該当投稿を非表示にできます（週に一度、自動でも実行されます）。

---

## 7. 設定・キャッシュ

ヘッダー右の歯車アイコンから設定を開きます。

- **アカウント**: ハンドル・DID・最終認証時刻の表示、ログアウト、セッションの検証。
- **キャッシュ**: 使用量（サムネ／原寸）と上限（既定 2GB）を表示。「**キャッシュを削除**」で全削除できます。
  - 上限を超えると、最後に使った時刻の古いものから自動で削除されます。
  - 削除してもメタ情報（どの投稿・どのメディアか）は残るため、次に開いたときに再取得されます。

---

## 8. オフライン時

ネットワークに繋がらないときは、ステータスバーに「**オフライン — キャッシュのみ表示中**」と表示され、すでにキャッシュ済みのメディアはそのまま閲覧できます。未取得のサムネは読み込めず、壊れた画像アイコンになります。接続が回復して同期すると通常表示に戻ります。

---

## 9. キーボードショートカット一覧

ショートカットは **Windows / macOS 共通**（すべて単一キー、修飾キー不要）です。

**グリッド**

| キー | 動作 |
|---|---|
| `/` | 検索フィールドにフォーカス |
| `Esc` | 検索解除／絞り込み解除／設定を閉じる |
| `r` | 手動で同期する |

**ライトボックス（拡大表示中）**

| キー | 動作 |
|---|---|
| `←` / `→` | 同一投稿内の前後のメディアへ |
| `o` | 元投稿を既定ブラウザで開く |
| `Space` | 動画の再生／一時停止 |
| `Esc` | ビューアを閉じる |

---

## 10. 困ったときは

- **ログインできない**: App Password（アカウント本体のパスワードではありません）を使っているか、ハンドルに誤りがないかご確認ください。
- **「再ログインが必要です」と出る**: 更新用トークンの期限切れです。設定からログアウトし、再度ログインしてください。
- **画像が壊れて表示される**: オフラインか、CDN 側で一時的に取得できない状態です。オンラインで再度開くと取得されます。
- **動画が再生できない**: 稀に環境依存で再生できない場合があります。その際は `o` で元投稿を開き、ブラウザでご覧ください。
